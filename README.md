# TERMizard

A terminal emulator and TUI framework written in Go.

## Requirements

- Go 1.26+

## Build

```bash
go build ./...
```

## Run

```bash
go run ./cmd/termizard
```

## Test

```bash
go test ./...
```

## Lint

```bash
golangci-lint run --timeout=5m
```

## Pre-release check

```bash
bash scripts/pre-release-check.sh
```
